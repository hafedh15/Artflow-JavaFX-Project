# 🎨 ArtFlow — Art Platform Desktop Application

A full-stack desktop application built with Java & JavaFX, designed 
to help artists sell their products, manage workshops, and get 
customer support.

## ✨ Features

- 🛍️ **Product Management** — Artists can list and sell their artwork
- 🎓 **Workshop Management** — Create and enroll in workshops
- 📝 **Article & Comment Management**
- 👥 **User Management** — Roles: Client, Artist, Admin
- 🖼️ **AI Profile Picture Generation**
- 📋 **Complaints System** — Real-time chat between users and support
- 🤖 **Dialogflow AI Chatbot** — 24/7 automated support when agents are offline
- 📊 **Admin Dashboard** — Full control over users, complaints, articles
- 🔔 **Complaint Status Tracking** — open / in progress / resolved

## 🚀 Getting Started

### Prerequisites
- Java JDK 11+
- JavaFX SDK
- XAMPP (MySQL)
- IntelliJ IDEA (recommended)

### Installation
1. Clone the repository
```bash
   git clone https://github.com/hafedh15/Artflow-JavaFX-Project.git
```
2. Import the project in IntelliJ IDEA
3. Start XAMPP and run MySQL
4. Run the application
